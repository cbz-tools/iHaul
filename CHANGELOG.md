# Changelog

## [0.1.5] - 2026-11-08

### Fixed
- Fixed drag-and-drop file transfers when a text field has focus.

## Unreleased

### Added

- Favorite apps can be reordered by drag and drop.
- An optional setting opens the top favorite and its `/Documents` folder on startup or connection.
- The optional startup opening is disabled by default.

### Changed

- Reduced idle CPU and GPU usage.
- Spinner animation runs at a lower rate.
- Clicking the only selected file again deselects it.
